# Croatian with Martin

Website for Martin Stier's Croatian lessons in Melbourne (Clifton Hill) and online.

Plain static site: `index.html`, `styles.css`, `script.js`, `assets/`. Open `index.html` in a browser to view it; no build step.

## Editing
- **Phone / WhatsApp:** search `index.html` for `423 476 299` and `470 48 53 09` (contact section and footer).
- **Email:** `lessonscroatiankorijeni@gmail.com` appears in `index.html` and at the top of `script.js`.
- **Colours:** the variables at the top of `styles.css` (`--red`, `--blue`, `--navy`).

## Publishing
Easiest free option is GitHub Pages: repo Settings → Pages → Deploy from branch → `main`, folder `/ (root)`.
